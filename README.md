# HockeyWerkstatt Website Version 2

Statische, responsive Landingpage für GitHub Pages.

## Dateien

- `index.html`: komplette Startseite
- `style.css`: responsives Premium-Design
- `script.js`: Navigation, Scroll-Effekte und Jahreszahl
- `images/logo-2b.png`: hier das horizontale Premium-Logo ablegen

## Logo einfügen

1. Logo 2B als einzelne PNG-Datei speichern.
2. Datei exakt `logo-2b.png` nennen.
3. Datei in den Ordner `images` hochladen.

Falls das Logo fehlt, zeigt der Header automatisch einen textbasierten Ersatz.

## GitHub Pages aktivieren

1. Alle Dateien in das Root-Verzeichnis des GitHub-Repositories hochladen.
2. Repository unter **Settings > Pages** öffnen.
3. Unter **Build and deployment** die Quelle **Deploy from a branch** wählen.
4. Branch **main** und Ordner **/(root)** wählen, dann speichern.

## Vor Veröffentlichung anpassen

- `info@hockeywerkstatt.ch` durch die definitive E-Mail-Adresse ersetzen.
- Instagram-Link im Footer ergänzen.
- Bestätigte Trainingsstandorte und Eiszeiten eintragen.
- Rechtliche Seiten wie Impressum und Datenschutzerklärung ergänzen.

## Formular

Das Formular nutzt `mailto:` und öffnet das E-Mail-Programm. Für eine serverlose Formularlösung kann später ein externer Formulardienst eingebunden werden.
